fintest Course

Structured Moodle-based lessons for learning practical software testing in financial services.

Note: The full course, lesson content, activities, and discussions are delivered securely through Moodle.

Continue to Moodle

Learning Modules

A. Financial Services Fundamentals

Understand the products, terminology, and business context behind banking, superannuation, insurance, payments, and wealth systems.

B. Testing Financial Processes

Learn how to test onboarding, transactions, contributions, claims, payments, transfers, fees, calculations, reconciliations, and reporting.

C. Data & ETL Testing

Learn source-to-target testing, transformation validation, reconciliation testing, SQL checks, and data quality rules.

D. Automation Testing

Learn how to approach regression testing, API testing, SQL-based checks, Python test automation, and CI/CD-friendly test execution.
